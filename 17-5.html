JavaScript 两种定时器

setTimeout 只执行一次，setInterval 每间隔一段时间重复执行

郑雯迪

ONCE setTimeout 一次性定时器

语法：var id = setTimeout(函数, 毫秒) —— 等待指定毫秒后只执行一次； 用 clearTimeout(id) 可以中途取消。下面的倒计时每滴答一次都会重新调用一次 setTimeout，正好说明它「只执行一次」的特点。

语法：var id = setInterval(函数, 毫秒) —— 每隔指定毫秒重复执行，直到调用 clearInterval(id) 才停止。

两种定时器对比

对比项 setTimeout setInterval
执行次数 只执行 1 次 每隔固定时间重复执行，直到被清除
常用函数 setTimeout(fn, ms) / clearTimeout(id) setInterval(fn, ms) / clearInterval(id)
返回值 数字 ID，用于取消 数字 ID，用于取消
典型场景 延迟提示、动画只播放一次、防抖、倒计时结束 时钟、轮播图自动切换、数据轮询刷新
注意事项 计时不准（主线程阻塞会推迟），需及时保存 ID 停止时必须 clearInterval，否则页面离开后仍可能继续运行

核心代码

// ① setTimeout：只执行一次
var id1 = setTimeout(function () {
    console.log('3 秒后，我只出现一次');
}, 3000);
clearTimeout(id1); // 中途取消

// ② setInterval：每 1 秒重复执行
var id2 = setInterval(function () {
    console.log('每秒打印一次');
}, 1000);
clearInterval(id2); // 停止重复执行
