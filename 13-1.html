原理说明

为什么一个 class 就能显示图标？

Font Awesome 在 CSS 中通过 @font-face 引入字体文件（woff2 / woff / ttf / eot / svg），再把每个图标定义为字体中的某个字符。当元素加上 class="fa fa-xxx" 时，CSS 的 :before 伪元素会插入对应字符，浏览器用字体渲染成图形。因此图标继承了文字的所有特性：可以像字号一样缩放，也可以直接用 color 改色，甚至能用 text-shadow 加阴影。
