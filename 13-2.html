Lucide
SVG 图标

Lucide 是一套开源的 SVG 图标库。它以 data-lucide 属性标记图标，再用 JS 把标记替换为真实的 SVG 元素，因此每个图标都是矢量图形，可以任意缩放与描边。

原理说明

为什么 data-lucide 能变成图标？

页面中的 <i data-lucide="home"> 只是一个占位标记。当脚本执行 lucide.createIcons() 时，Lucide 会根据属性值找到对应的 SVG 路径数据，把占位元素替换为真实的 <svg>。因为 SVG 是矢量图形，所以图标可以无损缩放；又因为描边默认使用 currentColor，所以直接用 CSS 的 color 就能改色。相比字体图标，SVG 图标还能用 stroke-width 控制线条粗细，并保留为可检查、可动画的 DOM 节点。
