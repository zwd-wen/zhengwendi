对象：键值对的集合

对象用 { key: value } 存储数据，点语法 obj.name 适合已知属性名， 方括号 obj['name'] 可以用变量做键。属性值也可以是函数，这时它叫「方法」。

字符串：不可变的字符序列

字符串可以通过 str[i] 或 charAt(i) 按下标访问（从 0 开始）， 但所有方法都不会修改原字符串，而是返回新字符串——试试上面的方法就明白了。

length 与遍历

length 是字符串最重要的属性；配合 for 循环或 split('') 转成数组，就能对每个字符做处理。模板字符串 `你好 ${name}` 则是拼接文字的现代写法。
