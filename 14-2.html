JavaScript 六种基础数据类型

郑雯迪 · 2026-10-22

JavaScript 的六种基础（原始）数据类型：String、Number、Boolean、 Null、Undefined、Symbol。 下方通过变量定义与 typeof 检测逐一演示每种类型的特征。

String 字符串

var yl_str = "你好";

Number 数字

var yl_num = 42;

Boolean 布尔值

var yl_bool = true;

Null 空值

var yl_null = null;

Undefined 未定义

var yl_undef;

Symbol 符号

var yl_sym = Symbol("id");
