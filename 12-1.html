CSS 变量

第一步 · 定义变量

以下色块全部由 :root 中的 CSS 变量渲染。

--zheng-coral
#d95d46 · 珊瑚红
--zheng-blue
#245b72 · 深蓝
--zheng-yellow
#f2c05c · 暖黄
--zheng-ink
#17212b · 墨色
:root { --zheng-coral: #d95d46; --zheng-blue: #245b72; --zheng-radius: 12px; } .zheng-card { color: var(--zheng-ink); border-radius: var(--zheng-radius); }
