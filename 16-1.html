mutate：会改变原数组

push / pop 操作尾部，shift / unshift 操作头部， splice 可在任意位置删除或插入，reverse 与 sort 直接原地排序。

纯函数：返回新值

slice 切片、concat 拼接、map / filter / reduce 加工数据时都不修改原数组，而是返回一个新数组或新值，这是现代 JS 推荐的写法。

sort 的小陷阱

sort() 默认把元素转成字符串再比较，所以 [15, 4, 8] 会排成 [15, 4, 8]。 数字排序必须传入比较函数 sort((a,b) => a-b)，试试上面两个按钮的差别！
